# Positive Technologies — тестовое задание

API для управления документами (20 полей разных типов) на .NET 10: CRUD, пагинация,
валидация, экспорт в отдельный сервис, события изменений.

> README заполняется по ходу работы. Разделы «Запуск» и «Архитектурные решения»
> будут дополнены после сборки каркаса.

## Стек

- .NET 10, ASP.NET Core Minimal API
- PostgreSQL 17, EF Core 10
- FluentValidation, OpenAPI + Scalar
- NUnit, Docker Compose
